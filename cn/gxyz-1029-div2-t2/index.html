AI 校车

题目描述

在藤养学园的新校区，一共有 $n$ 栋建筑，其中 $1$ 号建筑是充电站，这些建筑被 $n-1$ 条双向道路连通，形成了一棵以 $1$ 为根的树。

为了方便学生行动，藤养学园启用了一辆 AI 校车。这辆车可以同时容纳最多 $l$ 名乘客。

今天中午放学时段，校车恰在 $1$ 号建筑处充满电。接下来有 $m$ 位同学想乘车，第 $i$ 位同学当前位于建筑 $a_i$，他的目标是前往 $a_i$ 子树内的建筑 $b_i$。

现在，请你为校车规划一个送学生的方案，使得所有学生都能到达自己的目标，同时让校车的总行驶距离尽可能短。

注：允许让同一个学生多次上下车，可以参考样例一。

输入格式

从文件 bus.in 中读取数据。

第一行三个正整数 $n, l, m$，表示建筑的数量、校车的最大承载量和学生的数量。

接下来 $n-1$ 行，每行三个正整数 $x, y, z$，表示有一条从 $x$ 到 $y$ 的双向道路，长度为 $z$。

接下来 $m$ 行，每行两个正整数 $a, b$，表示一名学生想从 $a$ 出发到达 $b$。

输出格式

输出到文件 bus.out 中。

输出校车的最小运动总距离。

输入样例 1

输出样例 1

样例 1 解释

  • 有 $3$ 位同学，学生 1 从 $1$ 到 $5$，学生 2 从 $1$ 到 $4$，学生 3 从 $2$ 到 $4$。
  • 按照以下方案：
    1. 校车在建筑 $1$，让学生 1 和学生 2 上车；
    2. 车开到建筑 $2$，此时让学生 2 下车；
    3. 车载着学生 1 到建筑 $5$，此时学生 1 到达目的地；
    4. 空车回到建筑 $2$；
    5. 学生 2 和学生 3 上车，车载着两个学生一起到建筑 $4$。

输入样例 2~4

输出样例 2~4

数据范围与约定

  • 对于 $20%$ 的数据满足：$n \le 100$；
  • 对于另外 $20%$ 的数据满足：树的形态是一条链；
  • 对于另外 $20%$ 的数据满足：所有学生 $a = 1$；
  • 对于 $100%$ 的数据满足：
    • $1 \le n, l, m, z \le 10^5$；
    • $1 \le a_i, b_i \le n$，所有 $b_i$ 在 $a_i$ 的子树中。
